    📖 规则说明

    ⏱ 计时规则
    • 设置倒计时时间（或选择预设），点击「开始」计时
    • 计时中可暂停/继续，重置会清零
    • 倒计时归零自动记录学习时长
    • 长按计时器区域可手动记录已学习时长
    • 支持键盘快捷键：空格=开始/暂停，R=重置
    💰 积分规则
    • 1分钟学习 = 5积分
    • 1积分 = ¥0.01（1分钱）
    • 日学5小时 ≈ 1500分 ≈ ¥15
    • 周学35小时 ≈ 10500分 ≈ ¥105
    • 最少一次获得5积分
    🔥 连击倍率
    • 过去3天每天学满4小时，触发 x1.5 倍率
    • 倍率触发后，当天所有积分 ×1.5
    • 任意一天不足4小时，倍率恢复 x1.0
    • 倍率在积分卡片实时显示
    ⭐ 称号等级（基于终身学习积分，永不降级）
    🌰 种子选手（0-249）
    🌱 学习新芽（250-999）→ 升级奖励 +100 分
    🌿 学习达人（1000-2999）→ 升级奖励 +300 分
    🔥 学习高手（3000-7499）→ 升级奖励 +500 分
    ⭐ 学习大师（7500-14999）→ 升级奖励 +1000 分
    💎 学习传说（15000-24999）→ 升级奖励 +2000 分
    👑 无敌学习王（25000+）→ 升级奖励 +5000 分

    • 等级仅由学习时长获得的积分累计
    • 积分兑换后等级不下降
    • 每个等级奖励仅领取一次
    🎁 积分兑换
    • 积分可兑换实物奖励（零食、文具、裙子等）
    • 兑换后积分立即扣除
    • 💝 特别兑换：可自定义想要的东西
    • 特别兑换需要密码，且当日积分清零
    • 兑换记录可在兑换页面查看
    🎰 每周抽奖
    • 每周日刷新，免费1次抽取机会
    • 抽取随机任务，难度越高奖励越多
    • 完成任务后点「领取奖励」获得积分
    • 密码可增加抽取次数（最多5次/次）
    • 密码可重置本周抽奖
    🏷 标签统计
    • 计时前可选择学习科目标签（数学/英语等）
    • 支持自定义标签
    • 📊 统计页面按标签汇总学习时长
    • 彩色直方图直观展示各科学习情况
    ☁️ 云同步
    • 标题旁 ☁️ 图标设置 GitHub Token
    • 数据自动同步到 GitHub，多设备互通
    • 打开页面自动拉取最新数据
    • 学习记录变化后3秒自动推送
    • 也可用 📤导出/📥导入 JSON 文件手动同步
    🔐 密码管理
    • 默认密码：1234（可在设置中修改）
    • 密码用于：编辑积分、特别兑换、增加抽奖次数
    • 积分卡片右上角 🔧 进入管理
